
# Marcos Mateo — Portfolio personal

Portfolio web de presentación profesional de Marcos Mateo, estudiante de
Desarrollo de Aplicaciones Web (DAW) interesado en el desarrollo backend.

## Sobre el proyecto

Esta página web presenta mi perfil, formación académica, tecnologías,
proyectos de programación y datos de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub
- GitHub Pages para publicar la web

## Estructura del proyecto

- `index.html`: estructura y contenido de la página.
- `css/styles.css`: estilos y diseño adaptable.
- `img/perfil.jpg`: imagen del perfil.
